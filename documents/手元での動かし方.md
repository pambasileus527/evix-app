# 手元での動かし方

## Node.js で動かす

```bash
npm install
npm run dev
```

http://localhost:3000 を開く。本番と同じ形で確認するときは `npm run build && npm start`。

## Docker で動かす

[docker-起動方法.md](./docker-起動方法.md) を参照（`docker compose up`）。

## 環境変数

`.env.local` をプロジェクト直下に作る（Git には載らない）。雛形は `.env.example`。

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxx
```

Docker の場合も、同じ `.env.local` がフォルダごと読み込まれる。
