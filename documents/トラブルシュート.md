# 登録・公開で詰まったときの切り分け

| 症状 | 原因の場所 | 見る・直すところ |
| --- | --- | --- |
| 「送信中…」のまま止まる | Vercel に Supabase の接続情報がない・値が違う | 環境変数を確認して Redeploy |
| 「登録できませんでした」 | Supabase が登録を断った | 登録済みのメールではないか、メール送信の回数制限、Supabase の Authentication > Logs を確認 |
| 確認メールのリンクが開けない | URL Configuration の未設定 | Site URL と Redirect URLs を登録 |
| デプロイが「Blocked」 | コミット作者のメールが GitHub アカウントと不一致 | `git config user.name / user.email` を直して再 push |
| Build Failed（public が見つからない） | Framework Preset が Next.js でない | Settings > Build and Deployment で Next.js にして Redeploy |
| `git` が index.lock で止まる | 前の git 処理の残り | `rm -f .git/index.lock` |
| ログインしたのに `/login` へ戻る | ログイン状態はサイトごと | 開いているのが localhost か公開サイトか確認し、そのサイトでログインし直す |

詳しくは [システム構造と環境変数.md](./システム構造と環境変数.md) を参照。
