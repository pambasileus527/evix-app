# Vercel への公開

1. Vercel に GitHub アカウントでログインし、`evix-app` リポジトリだけを許可してインポートする
2. Framework が Next.js になっていることを確認する（Settings > Build and Deployment）
3. Environment Variables に Supabase の2つを入れる（[システム構造と環境変数.md](./システム構造と環境変数.md)）
4. Deploy する。以降は `main` に push すると自動で再デプロイされる
5. Supabase の Authentication > URL Configuration に公開URLを登録する

## コミットの注意

- コミットの作者（`git config user.email`）が、Vercel に紐付けた GitHub アカウントのメールと一致している必要がある（Hobby プラン）
- `.env.local` と `.tgz` はコミットしない（`.gitignore` 済み）
